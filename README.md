# PlanifProf

Outil de planification hebdomadaire pour enseignants — page web simple, sans backend.

## Fonctionnalités

- Grille horaire de la semaine (lundi à vendredi, par période) éditable directement
- Liste de tâches à faire avec priorité (haute / normale / basse)
- Sauvegarde automatique dans le navigateur (`localStorage`), aucune inscription ni serveur requis

## Utilisation

Ouvrir `index.html` dans un navigateur, ou héberger le dossier tel quel (ex. GitHub Pages).
